# API Testing — Postman

**Object:** reqres.in (public REST API)  
**Covered:** GET / POST / PUT / DELETE, status codes, response body & fields, basic schema validation

### How to run
1. Import `collection.json` into Postman
2. Run the collection (Runner) — all tests should pass
3. CLI option: `newman run collection.json`

### What it shows
- Request building
- Assertions in Postman Tests
- Positive & negative checks (including 404)
- Basic understanding of REST API testing
