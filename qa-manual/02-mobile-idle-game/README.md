# Mobile Idle Game — Manual Testing

Test assignment for a mobile idle / city-builder game (details anonymized).

### What was done
- GDD review (ambiguities + recommendations)
- Checklist (20 items)
- 20 test cases (positive, negative, boundary)
- 6 bug reports
- Core game loop analysis
- Testing approach based on STLC

### Project structure
| File | Description |
|------|-------------|
| [01-gdd-review.md](./01-gdd-review.md) | Review of Game Design Document — 10 ambiguities found |
| [02-checklist.md](./02-checklist.md) | Structured checklist (20 checks) |
| [03-test-cases.md](./03-test-cases.md) | Test cases with steps and expected results |
| [04-bug-reports.md](./04-bug-reports.md) | 6 bug reports with full structure |

### Key focus areas
- Parking & queue mechanics
- Cash desk / NPC flow
- Economy (income, upgrades, offline rewards)
- Rewarded ads & helicopter
- Core game loop

### Environment
- Platform: Android
- Testing type: Manual + Exploratory
